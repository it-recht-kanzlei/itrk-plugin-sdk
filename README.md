# Legal Text Interface specification and PHP SDK - IT-Recht Kanzlei


The Legal Text Interface (LTI) was developed by IT-Recht Kanzlei from Munich in order to transfer legal texts to
store systems and websites as easily and efficiently as possible.

## PHP-SDK

To help developers create a connection to the IT-Recht Kanzlei's legal text interface for their own systems,
the Kanzlei has developed a PHP-based SDK.

A complete description of how to use the SDK can be found in the following documents:

English: [SDK](docs/SDK.md) ([PDF Version](docs/SDK.pdf))  
German: [SDK DE](docs/SDK_de.md) ([PDF Version](docs/SDK_de.pdf))

## XML specification

If you work with a different programming language or cannot use the SDK, it is of course also possible to develop your own integration based on the XML specification.

A complete description of the XML LTI specification can be found in the following documents:

English: [LTI XML Specification](docs/LTI_XML_Specification.md) ([PDF Version](docs/LTI_XML_Specification.pdf))  
German: [LTI XML Specification DE](docs/LTI_XML_Specification_de.md) ([PDF Version](docs/LTI_XML_Specification_de.pdf))
